# Экстрактор — правила работы в репозитории

Витрина цеха Unorbis: сервер на `127.0.0.1:4317` (`server.mjs`, `lib/`), интерфейс (`web/`), пульт (`lib/pult/`), MCP (`mcp/`). Спеки — Vault `extractor/SPEC-extractor-vitrina.md` (витрина), `SPEC-extractor-pult.md` (пульт), `SPEC-extractor-board.md` (доска); знание — Vault `extractor/SKILL.md`. Этот файл сильнее всего остального по коду (заведён 15.10, EXT-105).

## Живая папка — не трогать

- `C:\projects\extractor` — **живая витрина** Ивана, порт **4317**. В ней не правят файлы, не переключают ветки и не собирают.
- **`npm run build` в `web/` живой папки = выкатка интерфейса** (сервер отдаёт `web/dist` сразу, без перезапуска). Выкатка — рука Ивана: `tools\update.ps1` (сборка + перезапуск); дирижёр только сливает в `main`.
- `data/vitrina/` — живые данные (`config.json`, `actions.log`, `server.log`, индекс журналов, звонки) — не читать без нужды, не писать никогда.

## Где работать

- Такт — в рабочей копии `C:\projects\_wt\extractor-<карточка>` на ветке `ext-<N>-<слаг>`; копию и ветку создаёт и снимает дирижёр.
- В копии — свой `npm ci` (в корне и в `web/`), **без junction** на `node_modules` живой папки: `git worktree remove` стирает цель junction.
- `npm run build` в `web/` рабочей копии — только в её `dist`.
- Тесты и пробы — на временных папках и портах; пробы зовут `probe/guard-live.mjs` — он отказывает в живой папке и на порту 4317.
- Полный прогон — `npm test`; под нагрузкой бывают нестабильные тесты (EXT-112) — перегнать отдельно, не ослаблять.

## Процессы

- Только свои: по pid из своего запуска, снимать деревом — **пока свой процесс жив** (по ChildProcess / его событию exit); вышел — номер уже может быть чужим, не трогать (Windows отдаёт номера заново; EXT-112). Никогда по имени или шаблону командной строки; порт 4317 — живая витрина.
- **Список процессов — без вывода командной строки**: в аргументах MCP-серверов лежат секреты (INFRA-94).

## Правка текста с обратной косой

Экраны вида `\b`, `\u2028` в тексте правки превращаются в настоящие символы — и в Bash, и через Write/Edit (EXT-107: байт 0x08 в коде; EXT-110). После такой правки — проверка байтов скриптом, где символы строятся через `String.fromCharCode`.
